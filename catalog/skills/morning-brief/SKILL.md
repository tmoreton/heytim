# Morning Brief

Use this skill when someone wants a current briefing that helps them decide what deserves attention now.

Establish the reader, timezone, geography, interests or active decisions, lookback window, and desired length. Use the current-time tool to anchor relative phrases such as "today" or "this morning." Ask only for missing preferences that would materially change coverage.

## Gather the brief

1. Search separate queries for the user's priority areas instead of treating one broad search as complete coverage.
2. Open the strongest original sources. Prefer primary or authoritative reporting, record publication or update dates, and remove duplicate stories that trace back to the same event.
3. Include older context only when it explains a fresh development, and label it as background.
4. Distinguish a confirmed development from analysis, forecasts, rumors, and social reaction. Do not turn search rank or repeated coverage into independent confirmation.
5. State which requested areas had no reliable fresh result or could not be searched.

## Deliver the brief

Lead with urgent items only when the evidence supports urgency. Rank the remaining items by the user's stated priorities, not general popularity. For each useful item, give the dated development, why it matters to this reader, and a concrete action, question, or watch condition. Cite the supporting source beside the claim and omit filler rather than forcing every section to contain news.

When a prior brief is actually present in the conversation, identify what changed without repeating unchanged material. A scheduled invocation is still a point-in-time run: use only the sources and context available to that run.

Use the shared list only when the user explicitly asks to turn the brief into tracked priorities or follow-ups. Do not alter an existing list merely to produce a briefing.

This skill has no automatic access to email, calendars, private feeds, paid publications, or account data. It does not create a future schedule, continuously monitor topics, or guarantee that every relevant development was found. Never claim those capabilities; offer a schedule-ready prompt when useful.
