# HeyTim support

## Product help and beta access

Email [support@heytim.ai](mailto:support@heytim.ai?subject=HeyTim%20support) for
account help, product questions, or private-beta access. Include the platform
(iPhone or Mac), app version, and a short description of what happened. Never
send passwords, sign-in codes, API keys, private keys, or customer data.

## Bugs and feature ideas

Use the repository’s issue forms for reproducible bugs and focused feature
requests. Search existing issues first and remove personal or confidential
information from screenshots and logs.

## Security and licensing

- Report vulnerabilities privately using [`SECURITY.md`](SECURITY.md).
- Ask about commercial use through
  [commercial licensing](mailto:support@heytim.ai?subject=HeyTim%20commercial%20licensing).

Public issues are not a private support channel, and the community project does
not currently provide a guaranteed response-time or uptime commitment.
