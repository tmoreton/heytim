# Contributing to HeyTim

Issues, bug reports, and focused design proposals are welcome.

HeyTim uses a source-available, dual-licensing model. To preserve the ability to
offer both PolyForm Noncommercial and commercial licenses, the project is not
currently accepting unsolicited source-code, documentation, bot, skill, or data
pull requests from outside contributors. Do not submit work you expect the
project to merge until a contributor agreement process is published.

Maintainers should follow the component-specific guidance in
[`catalog/CONTRIBUTING.md`](catalog/CONTRIBUTING.md) and the verification commands
in [`README.md`](README.md).

Security reports should be sent privately to
[support@heytim.ai](mailto:support@heytim.ai?subject=HeyTim%20security%20report),
not filed as public issues.
