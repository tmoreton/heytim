# Provider logos

These marks are bundled presentation assets. Provider authentication and tools remain defined by the backend provider registry, and an unknown provider falls back to its registry-supplied `iconText`.

- GitHub: official GitHub 2026 logo kit, `https://brand.github.com/GitHub_Logos.zip`
- Gmail, Google, and YouTube: Google Brand Resource Center assets, `https://about.google/brand-resource-center/products-and-services/`
- Slack: official Slack media-kit asset, `https://join.slack.com/media-kit`
- Notion: official Notion application mark, `https://www.notion.so/front-static/logo-ios.png`
- X: official X brand toolkit, `https://about.x.com/en/who-we-are/brand-toolkit`

The marks remain the property of their respective owners and are used only to identify the corresponding integration.
